# Documentacao Marcio TopBarber

Vault Obsidian oficial do projeto Marcio TopBarber.

## Abertura

1. Abra o Obsidian.
2. Selecione **Abrir pasta como cofre**.
3. Escolha `D:\dev\marciotopbarber\docs`.
4. Abra [[00-Inicio]].

## Regras

- não registrar senhas, tokens ou valores de `.env`;
- decisões estruturais devem ser registradas em [[ADRs]];
- documentação e código devem evoluir juntos;
- caminhos de código devem ser relativos ao repositório.
